# 캐릭터 이미지 제작 계획

- 기준: 사용자가 제시한 Anima 화풍 커스텀 → 표정·동작 확장 → 슈팅 화면용 픽셀 표현의 제작 흐름
- 대상: 레온 애쉬포드, 릴리안 블룸, 비비안 미스트우드, 엘레노어 나이트베일
- 연결 문서: [1차 디자인 시안](character_design_v01.md), [게임 기획서](../게임기획서.md), [리소스 계획서](../리소스계획서.md)
- 현재 단계: 사용자가 Anima에서 화풍을 다듬은 기준 이미지를 제공하기 전
- 이 문서는 후속 제작 기준이다. 아래 표정·동작·픽셀 파일은 아직 제작되지 않았다.

## 제작 흐름

1. 사용자가 1차 디자인 시안을 Anima로 커스텀하고 결과 이미지를 제공한다.
2. 제공한 이미지의 화풍, 얼굴, 머리 모양, 의상, 대표색과 장식을 기준으로 고정한다.
3. 같은 캐릭터의 표정과 몸 동작을 고해상도 이미지로 확장한다.
4. 전투 시점에 맞는 작은 픽셀 캐릭터를 별도로 설계한다.
5. 고정된 셀 안에서 동작 프레임을 제작하고 개별 PNG와 스프라이트 시트를 정리한다.
6. 대사 장면과 슈팅 장면에서 크기·가독성·동작 연결을 확인한다.

첫 제작은 캐릭터 한 명의 기본 표정, 표정 변화 하나, 전투용 대기·이동 샘플로 진행한다. 이 샘플에서 화풍과 픽셀 밀도를 정한 다음 나머지 표정과 캐릭터로 확장한다. 기본 시작 대상은 플레이어 레온으로 제안한다.

## 기준 이미지

제공된 Anima 결과물을 이후 제작의 시각적 기준으로 삼는다. 최초 디자인 보드는 캐릭터 설정을 확인하는 보조 자료로 사용한다.

- 전신 기본 자세를 우선하며, 얼굴과 손발·꼬리·날개가 잘리지 않은 이미지가 좋다.
- 얼굴이 작게 나온 전신 이미지에는 같은 디자인의 얼굴 확대 이미지가 있으면 표정 일관성을 맞추기 쉽다.
- 배경은 투명 또는 단순한 배경이 편리하다. 투명 배경을 입력의 필수 조건으로 삼지는 않는다.
- 이미지에서 확인되지 않는 뒷면이나 가려진 의상 부분은 새로 제안하는 디자인으로 구분한다.
- 캐릭터마다 얼굴 비율, 머리색, 의상 구조, 대표 장식과 색상표를 기록하고 변형 이미지에 적용한다.

## 감정 표현

대사 장면에서는 Anima에서 정한 화풍을 유지한다. 얼굴 표정에 따라 눈·눈썹·입을 바꾸되 인물의 얼굴형, 의상과 기본 구도를 맞춘다.

| 공통 표정 | 용도 | 캐릭터별 표현 방향 |
|---|---|---|
| 기본 | 평상시 대사 | 레온의 자신감, 릴리안의 밝음, 비비안의 여유, 엘레노어의 침착함 |
| 기쁨·미소 | 농담, 도발, 승리 | 같은 웃음도 허세·활기·능청·옅은 미소로 구분 |
| 분노 | 침입자와 대치 | 눈썹과 시선, 입의 긴장으로 표현 |
| 놀람·당황 | 예상 밖의 상황 | 얼굴 정체성을 유지하면서 눈과 입의 변화를 강조 |
| 결의·집중 | 전투 시작, 중요한 대사 | 시선과 자세를 단단하게 정리 |
| 피로·피격 | 전투 후 반응 | 과한 상처 표현 없이 표정과 자세로 전달 |

기존 계획의 대사 초상화는 320 × 480 px PNG다. 이를 초기 출력 기준으로 사용하고, 고해상도 제작 원본은 별도로 보관한다. 표정별 파일은 동일한 캔버스, 얼굴 위치, 확대율을 사용한다. 별도의 포즈 연출용 전신 이미지는 초상화와 구분해 보관한다.

## 몸 동작

| 동작 | 고해상도 이미지에서 표현할 내용 | 전투용 픽셀 이미지에서 표현할 내용 |
|---|---|---|
| 대기 | 기본 자세, 호흡, 가벼운 표정 | 몸의 작은 움직임과 망토·날개·꼬리의 보조 움직임 |
| 왼쪽·오른쪽 이동 | 몸 기울기와 팔다리 자세 | 이동 방향이 읽히는 기울기와 장식의 반응 |
| 공격·시전 | 손동작과 캐릭터별 마법 자세 | 짧고 읽기 쉬운 시전 동작 |
| 피격 | 움찔하거나 균형을 잃는 자세 | 짧은 반응. 무적 시간의 깜빡임은 게임 로직으로 처리 |
| 등장·퇴장 | 대사와 전투를 잇는 자세 | 기본 동작 재사용을 우선하고 필요하면 별도 제작 |
| 승리·패배 | 성격을 드러내는 결과 자세 | 결과 화면에서 필요한 경우에만 추가 |

고해상도 포즈는 동작의 기준 이미지다. 전투 애니메이션은 중간 프레임, 연결, 무게중심과 보조 움직임을 따로 맞춰 제작한다.

## 슈팅 화면의 픽셀 표현

원화를 단순히 작게 줄이는 방식으로 끝내지 않는다. 작은 크기에 맞춰 실루엣과 색 덩어리를 다시 정리하고, 세부 장식과 명암 단계를 줄인다.

- 레온: 보라색 망토와 붉은 마력 문양을 남긴다.
- 릴리안: 녹색 꽃잎 의상, 흰 꽃과 작은 날개를 남긴다.
- 비비안: 여우 귀와 푸른 의상, 크게 휘는 꼬리를 남긴다.
- 엘레노어: 은발과 남색 의상의 대비, 달 장식을 남긴다.
- 생성할 때 픽셀풍 외형만 흉내 내는 데 그치지 않고, 최종 셀의 격자에 맞는 픽셀 크기와 경계를 확인한다.
- 셀 경계의 픽셀은 또렷하게 유지한다. 표시 시 보간으로 흐려지지 않도록 최근접 샘플링과 정수 배율 확대를 우선 검토한다.
- 전투에서는 플레이어와 보스의 위치·공격 방향이 읽혀야 한다. 첫 샘플에서 플레이어의 후방 또는 약한 탑다운 시점과 보스의 정면 시점을 비교해 정한다.
- 표정의 세부는 대사 초상화가 담당하고, 작은 전투 이미지에서는 자세와 큰 색 변화가 감정을 전달한다.

| 캐릭터 | 기존 전투 셀 기준 | 기본 시트 기준 |
|---|---|---|
| 레온 | 32 × 48 px | 4열 × 3행, 128 × 144 px |
| 릴리안 | 64 × 64 px | 4열 × 2행, 256 × 128 px |
| 비비안 | 64 × 64 px | 4열 × 2행, 256 × 128 px |
| 엘레노어 | 64 × 64 px | 4열 × 2행, 256 × 128 px |

위 규격을 첫 샘플의 기준으로 삼는다. 날개·꼬리·망토가 잘리거나 화면에서 구별되지 않으면 샘플을 보며 셀 크기와 표시 크기를 함께 조정한다. 확장 동작은 기존 시트의 칸에 무리하게 넣지 않고 동작별 추가 시트로 분리할 수 있다.

## 파일 구성

| 구분 | 출력 방향 | 예시 |
|---|---|---|
| 기준 원화 | 제공받은 원본과 캐릭터 설정 | Anima 결과물 원본 |
| 고해상도 표정·포즈 | 표정 또는 포즈별 PNG | `leon_angry.png`, `leon_cast.png` |
| 대사 초상화 | 표정별 320 × 480 투명 PNG | `leon_portrait.png`, `leon_portrait_angry.png` |
| 전투 개별 프레임 | 같은 크기의 투명 RGBA PNG | `leon_idle_00.png`, `leon_move_left_00.png` |
| 전투 스프라이트 시트 | 동작별 또는 기본 동작 묶음 | `leon_sheet.png`, `leon_cast_sheet.png` |
| 프레임 정보 | 시트와 함께 사용하는 제작 정보 | 셀 크기, 행·열, 프레임 순서·시간, 반복 여부, 기준점 |

파일명 접두어는 `leon`, `lillian`, `vivian`, `eleanor`로 통일한다. 고해상도 제작 원본과 게임에 넣을 작은 출력물을 분리한다. 프레임 정보의 실제 파일 형식과 게임에서의 로딩 방식은 애니메이션 구현에 맞춰 정한다.

## 출력 확인 기준

- 같은 캐릭터의 얼굴, 의상 구조, 대표색과 장식이 표정·동작 사이에서 유지된다.
- 프레임별 캔버스 크기와 기준점이 같고, 의도하지 않은 위치 흔들림이 없다.
- 망토·날개·꼬리와 손발이 셀 경계에서 잘리지 않는다.
- 시트의 셀 간격은 0이며, 셀 내부에 약 2 px의 투명 여백을 확보한다.
- 투명 배경에 사각형 잔상이나 불필요한 테두리 픽셀이 없다.
- 전투 배경 위에서 캐릭터와 탄환, 피격 중심점이 구별된다.
- 이미지 외곽과 충돌 판정 크기를 분리한다.
- 애니메이션은 프레임 연결과 반복 경계를 확인한다.
- Windows의 실제 이미지 표시·애니메이션과 Visual Studio 컴파일·실행은 사용자가 확인한다.
